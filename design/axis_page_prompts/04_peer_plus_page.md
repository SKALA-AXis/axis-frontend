# 04. Peer+ 분석 페이지 구현 프롬프트

## AI에게 전달할 요청
너는 기존 AXIS 프론트엔드 프로젝트의 공통 레이아웃을 유지하면서 Peer+ 분석 페이지의 본문만 새로 구현하는 프론트엔드 개발자다. 이 화면은 기존에 진행해 온 Peer/경쟁사 비교 분석 기능을 기반으로 한다. 헤더, 좌측 사이드바, 검색창은 그대로 유지하고, 본문에는 기업명 입력, AI 비교 요약, IR·DART 기반 차트, 관련 뉴스 영역을 배치한다.

## 페이지 목적
사용자가 특정 기업명을 입력하면 해당 기업과 Peer 기업 간 차이, 유사점, 시장 포지션, 최근 이슈를 한 화면에서 확인할 수 있게 한다. 단순 검색 결과가 아니라 “AI가 비교해서 정리한 분석 화면”처럼 보여야 한다.

## 본문 레이아웃
본문 상단 왼쪽에는 `기업명` 입력 박스를 둔다. 오른쪽 상단에는 연한 초록색 `필터` 버튼 또는 칩을 배치한다. 그 아래에는 큰 분석 카드 두 개를 가로로 배치한다. 왼쪽 카드는 `SK AX 인텔리전스와 Peer사는 이렇게 달라요` 같은 비교 요약 카드다. 이 카드에는 AI가 추출한 핵심 차이 3개, 강점/약점, 시장 변화 요약을 넣는다. 오른쪽 카드는 `IR 자료 기반 이미지/차트` 영역으로, 재무·사업·투자 포인트를 차트 또는 썸네일 형태로 보여준다.

하단에는 `보이는 기업 관련 뉴스` 영역을 둔다. 뉴스는 카드 리스트 또는 가로 스크롤 카드로 구성한다. 각 뉴스 카드에는 제목, 출처, 날짜, 요약, 관련 키워드를 표시한다. 스케치에 있는 이미지·차트 메모를 반영해 뉴스 카드에는 필요 시 썸네일 영역을 포함한다.

## 데이터 매핑
기업 입력값은 `targetCompany`로 관리한다. 비교 대상은 `peerCompanies` 배열로 관리한다. AI 분석 결과는 `comparisonSummary`, `differencePoints`, `similarityPoints`, `riskSignals`, `opportunitySignals`로 나눈다. IR/DART 데이터는 `financialMetrics`, `dartIndicators`, `chartImages`로 분리한다. 뉴스 데이터는 `companyNews` 배열로 관리하며, 각 항목은 `title`, `source`, `publishedAt`, `summary`, `keywords`, `thumbnailUrl`을 가진다.

## 상호작용
기업명을 입력하고 엔터 또는 분석 버튼을 누르면 Peer 분석 결과가 갱신되는 구조를 만든다. 필터에서는 비교 기간, Peer 그룹, 데이터 출처, 뉴스 기간을 선택할 수 있게 한다. 비교 요약 카드 클릭 시 상세 비교 페이지로 이동하고, IR 차트 카드 클릭 시 레이더차트 또는 DART 상세 화면으로 이동한다. 뉴스 카드는 클릭 시 원문 또는 내부 뉴스 상세 모달을 연다.

## 디자인 규칙
분석 화면이므로 정보 위계가 중요하다. 기업명 입력은 작지만 눈에 잘 띄어야 하고, AI 비교 요약 카드는 가장 먼저 읽히게 배치한다. 카드 스타일은 홈 대시보드와 동일한 테두리·배경 톤을 유지한다. 필터 칩은 기존 스케치처럼 연한 초록색 계열을 사용한다.

## 완료 기준
기업 입력, 필터, 비교 요약 카드, IR/DART 차트 카드, 관련 뉴스 영역이 모두 존재해야 한다. mock 데이터만으로 기본 화면이 채워져야 하며, 입력값 변경에 따라 화면 상태가 갱신될 수 있는 구조여야 한다.
