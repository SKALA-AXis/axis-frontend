# 01. 홈 대시보드 페이지 구현 프롬프트

## AI에게 전달할 요청
너는 기존 AXIS 프론트엔드 프로젝트의 UI 구조를 유지하면서, 홈 대시보드의 본문 영역만 교체하는 프론트엔드 개발자다. 전체 레이아웃은 첨부 와이어프레임과 동일하게 유지한다. 상단에는 좌측 AXIS 로고, 중앙 검색창, 우측 `L/D`, 채팅, 알림 아이콘이 있는 헤더를 둔다. 좌측에는 고정 사이드바를 둔다. 본문은 회색 톤의 카드형 대시보드로 구성하며, “과거와의 변화를 기반으로 오늘의 동향”을 빠르게 파악하는 첫 진입 화면이 되어야 한다.

## 페이지 목적
사용자가 로그인 후 가장 먼저 보는 화면이다. 오늘의 핵심 동향을 과거 데이터와 비교해 요약하고, 아래 영역에서 관련 그래프를 바로 확인하거나 상세 페이지로 이동할 수 있어야 한다. 이 페이지는 “오늘 무엇이 달라졌는가”를 한눈에 보여주는 허브 역할을 한다.

## 본문 레이아웃
본문은 크게 상단 인사이트 영역과 하단 그래프 영역으로 나눈다. 상단 왼쪽에는 가장 큰 메인 카드가 들어간다. 카드 중앙에는 큰 문구로 `과거와의 변화를 기반으로 오늘의 동향`을 배치하고, 하단 또는 보조 텍스트 영역에 오늘의 핵심 변화 요약, 상승/하락 키워드, 과거 대비 변화율을 표시한다. 상단 오른쪽에는 세로형 보조 카드가 들어가며, 이 카드에는 오늘의 요약 카드뉴스, 주요 이슈 1~3개, 또는 AI가 추출한 대표 시사점을 넣는다. 하단에는 동일한 높이의 카드 3개를 가로 배치한다. 왼쪽은 선그래프, 중앙은 DART 기준 레이더차트, 오른쪽은 막대그래프 영역이다.

## 데이터 매핑
메인 카드에는 과거 기간 대비 오늘의 변화 요약 데이터를 연결한다. 예시는 `오늘 감지된 변화`, `전주/전월 대비`, `핵심 키워드`, `AI 요약`이다. 선그래프는 시간 흐름에 따른 관심도 또는 언급량 변화, 레이더차트는 DART 기반 재무/사업/시장 지표 비교, 막대그래프는 키워드별 빈도·영향도·증감률 중 하나를 표현한다. 실제 API가 없다면 mock 데이터 구조를 분리해 두고 나중에 쉽게 교체할 수 있도록 구현한다.

## 상호작용
검색창에서 키워드 또는 기업명을 입력하면 홈 요약 카드와 그래프가 필터링될 수 있도록 상태 구조를 준비한다. 메인 카드 클릭 시 오늘의 인사이트 상세 페이지로 이동한다. 오른쪽 요약 카드 클릭 시 카드뉴스 페이지로 이동한다. 하단 그래프 카드 클릭 시 각각 선그래프 상세, 레이더차트 상세, 막대그래프 상세 또는 키워드 그래프 페이지로 이동할 수 있게 한다.

## 디자인 규칙
스케치처럼 전체 화면은 밝은 회색 배경 위에 검은 테두리 느낌의 카드 구획을 사용한다. 다만 실제 구현에서는 과하게 두꺼운 선보다 `border`, `rounded`, `shadow-sm` 수준의 정돈된 카드 스타일을 적용한다. 텍스트 위계는 메인 문구가 가장 크고, 카드 제목, 보조 설명, 수치 순으로 명확하게 구분한다. AXIS 로고는 붉은색 강조를 유지한다. 좌측 사이드바와 상단 헤더는 기존 프로젝트 컴포넌트를 재사용한다.

## 완료 기준
기존 프레임은 유지되고 본문 대시보드만 교체되어야 한다. 카드 5개가 와이어프레임과 같은 비율로 배치되어야 하며, 반응형 화면에서는 하단 3개 카드가 1열 또는 2열로 자연스럽게 줄바꿈되어야 한다. 각 카드에는 추후 API 연동을 위한 명확한 props 또는 mock data가 분리되어 있어야 한다.
