# 08. 키워드 그래프 페이지 구현 프롬프트

## AI에게 전달할 요청
너는 기존 AXIS 프론트엔드 프로젝트의 공통 레이아웃을 유지하면서 키워드 그래프 페이지의 본문만 구현하는 프론트엔드 개발자다. 첨부 스케치처럼 본문 대부분을 차지하는 큰 그래프 캔버스가 있고, 중앙에는 3D 구 또는 네트워크 그래프가 표시되어야 한다. 헤더와 사이드바는 그대로 유지한다.

## 페이지 목적
사용자가 오늘의 동향, 기업 분석, 카드뉴스, Peer 분석에서 추출된 키워드 관계를 시각적으로 탐색하는 화면이다. 키워드 간 연결 강도, 군집, 중요도, 변화 방향을 2D 또는 3D 그래프로 표현한다. 핵심은 “관계망을 크게 보여주는 페이지”다.

## 본문 레이아웃
본문 전체를 하나의 큰 그래프 영역으로 사용한다. 그래프 영역 상단 왼쪽에는 `키워드 그래프` 제목을 표시하고, 오른쪽에는 그래프 기준을 선택하는 작은 컨트롤을 둔다. 컨트롤은 기간, 데이터 출처, 기업/산업 필터, 그래프 타입을 포함한다. 중앙에는 3D 구 형태의 키워드 네트워크 또는 force-directed graph를 배치한다. 각 노드는 키워드를 의미하고, 선은 키워드 간 관계를 의미한다.

그래프 하단 또는 우측에는 선택된 키워드의 상세 패널을 둘 수 있다. 상세 패널에는 키워드명, 중요도, 언급량, 전일 대비 변화, 연결 키워드, 관련 뉴스/인사이트 링크를 표시한다. 단, 스케치처럼 그래프 공간이 가장 커야 하므로 상세 패널은 접었다 펼칠 수 있게 한다.

## 데이터 매핑
그래프 데이터는 `nodes`와 `edges`로 분리한다. `nodes`는 `id`, `label`, `size`, `category`, `score`, `changeRate`를 가진다. `edges`는 `source`, `target`, `weight`, `relationType`을 가진다. 기존 홈 대시보드, Peer 분석, 카드뉴스, 뉴스 요약에서 추출된 키워드 데이터를 연결할 수 있도록 `sourceType`과 `sourceId`를 포함한다. API가 없다면 mock graph data를 별도 파일로 분리한다.

## 상호작용
노드를 클릭하면 해당 키워드가 선택되고 상세 패널이 열린다. 노드에 hover하면 키워드명과 점수를 tooltip으로 표시한다. 필터를 변경하면 그래프 데이터가 재계산되거나 필터링된다. 그래프 확대/축소, 드래그 이동, 초기화 버튼을 제공한다. 특정 노드를 더블클릭하면 관련 인사이트 결과 페이지 또는 카드뉴스 페이지로 이동할 수 있다.

## 디자인 규칙
그래프 페이지는 시각화가 주인공이다. 다른 UI 요소는 최소화하고 그래프 캔버스를 넓게 확보한다. 배경은 밝은 회색 또는 흰색으로 두고, 노드 크기와 연결선 굵기로 중요도와 관계 강도를 표현한다. 3D 구현이 부담스럽다면 2D force graph로 시작하되, 컴포넌트 이름과 데이터 구조는 3D 그래프로 확장 가능하게 만든다.

## 완료 기준
큰 그래프 캔버스, 제목, 필터 컨트롤, 노드/엣지 기반 시각화, 선택 키워드 상세 패널이 구현되어야 한다. mock 데이터만으로 키워드 네트워크가 표시되어야 하며, 노드 선택·hover·필터 변경이 동작해야 한다.
