# 06. 인사이트 결과 페이지 구현 프롬프트

## AI에게 전달할 요청
너는 기존 AXIS 프론트엔드 프로젝트의 공통 레이아웃을 유지하면서 인사이트 결과 페이지의 본문만 구현하는 프론트엔드 개발자다. 이 화면은 분석 또는 매칭 이후 생성된 `New 인사이트`를 상세하게 보여주는 페이지다. 헤더와 좌측 사이드바는 그대로 두고, 본문에는 인사이트 흐름도, 본문 요약, 관련 이미지/콘텐츠 카드, 추천 후속 액션을 배치한다.

## 페이지 목적
사용자가 AI 분석 결과를 단순 텍스트가 아니라 구조화된 흐름으로 이해하게 하는 화면이다. 스케치처럼 상단에는 `New 인사이트` 제목과 도형 흐름이 있고, 중앙에는 긴 설명 박스, 오른쪽에는 관련 콘텐츠 썸네일 카드가 배치된다.

## 본문 레이아웃
본문 상단 왼쪽에는 `New 인사이트` 제목을 크게 표시한다. 그 아래 또는 오른쪽에는 원형·화살표·막대형 도형을 활용한 흐름도를 배치한다. 흐름도는 `원인`, `변화`, `영향`, `대응` 같은 단계로 구성한다. 흐름도 아래에는 넓은 텍스트 카드가 들어가며, 이 카드에는 인사이트 요약, 근거 데이터, 시사점, 추천 액션을 문단 또는 bullet 형식으로 정리한다.

본문 오른쪽에는 세로형 썸네일 카드 2개를 배치한다. 각 카드는 관련 이미지, 그래프, 카드뉴스, 기사 또는 내부 분석 자료를 연결한다. 스케치의 우측 작은 카드처럼 이미지 영역과 짧은 제목을 포함한다. 하단에는 `관련 데이터 보기`, `카드뉴스 생성`, `그래프로 보기`, `보고서에 추가` 같은 액션 버튼을 배치한다.

## 데이터 매핑
이 페이지의 핵심 데이터는 `insightResult` 객체로 관리한다. 필드는 `title`, `summary`, `flowSteps`, `evidence`, `implications`, `recommendedActions`, `relatedAssets`로 구성한다. `flowSteps`는 단계명, 설명, 상태, 아이콘 타입을 가진 배열이다. `relatedAssets`는 이미지, 그래프, 카드뉴스, 뉴스, 보고서 등으로 연결될 수 있도록 `assetType`, `title`, `thumbnailUrl`, `targetUrl`을 가진다.

## 상호작용
흐름도의 각 단계를 클릭하면 해당 단계의 설명이 중앙 텍스트 카드에 강조 표시된다. 관련 콘텐츠 카드를 클릭하면 미리보기 모달 또는 상세 페이지로 이동한다. `카드뉴스 생성` 버튼은 카드뉴스 페이지로 현재 인사이트 데이터를 넘긴다. `그래프로 보기` 버튼은 키워드 그래프 또는 차트 상세 페이지로 이동한다.

## 디자인 규칙
결과 페이지는 설명력이 중요하므로 본문 텍스트 카드의 가독성을 높인다. 흐름도는 단순한 선형 구조로 만들고, 과도한 애니메이션은 피한다. 오른쪽 콘텐츠 카드는 보조 정보이므로 중앙 인사이트 영역보다 작게 유지한다. 전체 색상은 AXIS의 회색 카드 톤을 유지하되, 핵심 인사이트 제목과 선택 단계만 강조색을 사용한다.

## 완료 기준
`New 인사이트` 제목, 단계형 흐름도, 중앙 설명 카드, 관련 콘텐츠 카드 2개 이상, 후속 액션 버튼이 모두 구현되어야 한다. mock 데이터만으로도 완성된 결과 페이지처럼 보여야 하며, 이후 API 데이터가 들어와도 구조가 깨지지 않아야 한다.
