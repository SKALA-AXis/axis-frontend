# 05. 카드뉴스 페이지 구현 프롬프트

## AI에게 전달할 요청
너는 기존 AXIS 프론트엔드 프로젝트의 공통 프레임을 유지하면서 카드뉴스 페이지의 본문만 구현하는 프론트엔드 개발자다. 이 화면은 분석 결과를 카드뉴스 형태로 보여주고, 제목 변환 흐름과 릴스/숏폼 변환 가능성을 함께 표시하는 콘텐츠 관리 화면이다. 헤더와 사이드바는 그대로 두고, 본문에는 필터와 카드뉴스 목록을 배치한다.

## 페이지 목적
AI가 생성한 인사이트, 뉴스 요약, 기업 분석 내용을 카드뉴스 단위로 정리해 사용자가 빠르게 검토하고 선택할 수 있게 한다. 스케치의 핵심은 `필터` 아래 카드들이 반복 배치되고, 카드 간에 `제목변환 흐름` 또는 콘텐츠 변환 흐름이 표현되는 것이다.

## 본문 레이아웃
본문 상단에는 연한 초록색 pill 형태의 `필터` 영역을 둔다. 필터 아래에는 카드뉴스 목록을 그리드로 배치한다. 기본은 3열 그리드이며, 각 카드에는 콘텐츠 제목, 카드뉴스 타입, 릴스/숏폼 예상 길이, 핵심 키워드, 생성 상태를 표시한다. 스케치의 파란 메모처럼 각 카드에는 `릴스버전 18초`와 같은 파생 콘텐츠 정보를 넣을 수 있다.

카드 사이에는 필요 시 `제목변환 흐름`을 나타내는 작은 화살표 또는 연결선을 표현한다. 예를 들어 원본 뉴스 제목 → 카드뉴스 제목 → 릴스 제목의 변환 단계를 카드 안에서 단계형 텍스트로 보여준다. 하단에는 추가 카드가 이어지는 구조로 충분한 스크롤 공간을 둔다.

## 데이터 매핑
카드뉴스 데이터는 `id`, `originalTitle`, `cardNewsTitle`, `shortFormTitle`, `summary`, `keywords`, `durationSec`, `status`, `sourceType`, `createdAt` 필드를 가진 배열로 관리한다. 필터 조건은 `status`, `sourceType`, `keyword`, `dateRange`로 분리한다. 기존에 생성한 인사이트, Peer 분석, 뉴스 요약 데이터와 연결할 때는 `sourceId`를 통해 원본 분석 결과를 추적할 수 있게 한다.

## 상호작용
필터를 클릭하면 상태, 출처, 기간, 키워드를 선택할 수 있다. 카드 클릭 시 카드뉴스 상세 또는 편집 모달을 연다. 카드 안에는 `미리보기`, `제목 재생성`, `릴스 변환`, `선택` 버튼을 배치한다. 여러 카드를 선택한 뒤 일괄 내보내기 또는 저장할 수 있는 액션 영역을 하단 고정 또는 우측 상단에 둔다.

## 디자인 규칙
카드뉴스 페이지는 콘텐츠 썸네일을 다루므로 카드 간 간격을 충분히 두고, 각 카드가 독립적인 콘텐츠 단위로 보이게 한다. 필터는 초록색 강조를 유지한다. 선택된 카드에는 체크 아이콘과 강조 테두리를 적용한다. 상태값은 `초안`, `검토중`, `완료`, `내보냄`처럼 배지로 표현한다.

## 완료 기준
필터, 카드뉴스 그리드, 카드별 변환 흐름, 릴스/숏폼 정보, 카드 액션 버튼이 모두 포함되어야 한다. mock 데이터 기반으로 6개 이상의 카드가 렌더링되어야 하며, 필터와 선택 상태가 동작해야 한다.
